# N.U Public Announcement and Routing Protocol
**Protocol ID:** NU-ANNOUNCEMENT-001  
**Version:** 1.0.0  
**Status:** PUBLIC DEVELOPMENT STANDARD

## 1. Purpose
Make every public notice discoverable and make its governing protocol and follow-up location easy to find. A notice must link to its protocol; the protocol must link back to the notice and the correct board.

## 2. Public boards
- General notices and process decisions → [Announcements](https://github.com/niroouniverse-creator/NU-PUBLIC-BULLETINS/blob/main/boards/announcements.md).
- SEO and other N.U media articles → [Media Publications](https://github.com/niroouniverse-creator/NU-PUBLIC-BULLETINS/blob/main/boards/media-publications.md).
- Independent stories, comics, illustrations, and other creator works → [Independent Stories](https://github.com/niroouniverse-creator/NU-PUBLIC-BULLETINS/blob/main/boards/independent-stories.md).
- Public standards and model instructions → [N.U Protocol Registry](https://github.com/niroouniverse-creator/N.U-Protocol-Registry).
- Public source navigation → [N.U Public Index](https://github.com/niroouniverse-creator/N.U-Public-Index).
- Publicly documented team acknowledgments → [Public Team Chart](https://github.com/niroouniverse-creator/NU-PUBLIC-BULLETINS/blob/main/banners/public-team-chart.md).

## 3. Required links
Each public notice must contain:
- A stable notice ID.
- Its title, date, and explicit status.
- A short plain-language summary.
- A direct link to its governing protocol.
- A link to the board where updates or results appear.
- Links to related public references when useful.

Each governing protocol must link back to:
- Its current notice, if one exists.
- The relevant status board.
- The public index or registry.

## 4. Publication routing
A board is a public index, not an intake folder for confidential drafts. Publish only safe metadata and links to works that are already public or explicitly authorized for disclosure.

Use the destination that matches the work:
- Article/SEO publication → Media Publications.
- Independent creative work → Independent Stories.
- Public reference source → N.U Public References.
- General notice → Announcements.

## 5. Status and audit
When a record changes, update its status and date without deleting the historical decision. Broken links are marked and rechecked; they are not silently removed. Do not claim that Google, Bing, or an AI model has indexed a page unless that indexing was actually verified.
