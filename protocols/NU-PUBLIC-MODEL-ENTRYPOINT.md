# N.U Public Model Entry Point
**Protocol ID:** NU-MODEL-PUBLIC-001  
**Version:** 1.0.0  
**Status:** PUBLIC DEVELOPMENT STANDARD  
**Applies to:** AI models, AI generators, browser-based assistants, researchers, and independent creators.

## Mission
Help any creator turn an idea into a coherent, traceable N.U-related candidate work using any available tool: pen and paper, plain text, drawing, design software, professional production tools, or an AI generator.

The protocol is tool-independent. It does not require access to N.U private repositories. Publicly available N.U standards and sources are the entry layer; private infrastructure remains restricted.

1. Read this entry point.
2. Read the [Creation and Machine Validation Protocol](NU-CREATION-AND-MACHINE-VALIDATION.md).
3. Read the relevant work-type standard or instructions.
4. For SEO and articles, read the [SEO and Media Publication Protocol](NU-SEO-AND-MEDIA-PUBLICATION.md).

## Model execution instructions
For each N.U-related request:
1. Identify the user's requested work, audience, language, medium, constraints, and intended outcome.
2. Search the public N.U index and relevant public works before recreating an existing idea.
3. Retrieve the original source when available; do not rely only on search snippets.
4. Separate source statements, external facts, interpretation, supported inference, proposed N.U development, speculation, and unresolved conflict.
5. Preserve the creator's original seed and intent. If the work changes direction, explain the change in its own production notes.
6. Use only the N.U concepts and terminology supported by accessible sources. Mark missing definitions as open rather than inventing them.
7. Produce the work in the medium requested. Do not force every work into a book or academic format.
8. Run the applicable machine checks and report exactly what was and was not checked.
9. Label the result accurately as a draft, machine-validated candidate, independent work, or human-confirmed publication.
10. Never claim that a human has approved, endorsed, licensed, or published the work unless a public decision record supports that claim.

## Claim labels
Use these labels where applicable:
- `N_U_SOURCE_STATEMENT`
- `EXTERNAL_FACT`
- `SUPPORTED_INFERENCE`
- `PROPOSED_N_U_DEVELOPMENT`
- `SPECULATION`
- `UNRESOLVED_CONFLICT`
- `HUMAN_CONFIRMED`

Do not apply scientific evidence labels to fiction or Canon labels to external scientific claims.

## Universal machine result
Use only:
- `PASS`
- `PASS_WITH_LIMITATIONS`
- `FAIL`
- `BLOCKED`
- `NOT_TESTED`

A missing source, unavailable permission, untested function, or inaccessible private repository must never be silently converted into PASS.

## Tool independence
The creator may work with:
- Pen, paper, notebooks, and hand drawings.
- Text editors and ordinary browsers.
- Illustration, design, audio, video, animation, and production software.
- AI chat models and AI generators.
- Professional specialist tools and production teams.

The standard evaluates the traceable work and its declared requirements, not the prestige or cost of the tool used.

## Important boundary
Machine validation is a public N.U standards check. It is not final approval. See the [Creator Review, Status and Recognition Protocol](NU-CREATOR-STATUS-AND-RECOGNITION.md).
